# Attendance Management System (Django + MySQL)

This is a Django-based Attendance Management System designed to help educational institutions track and manage student attendance efficiently.

## 🚀 Features

- Secure user authentication (Admin, Teacher, Student)
- Mark attendance daily per course
- View attendance statistics
- Admin dashboard for managing users and data
- MySQL as the backend database
- Environment variables managed using `.env` file

## 🛠️ Tech Stack

| Layer       | Technology       |
|-------------|------------------|
| Backend     | Django (Python)  |
| Database    | MySQL            |
| Auth        | Django's built-in auth system |
| Deployment  | Localhost (can be pushed to Heroku or AWS) |
